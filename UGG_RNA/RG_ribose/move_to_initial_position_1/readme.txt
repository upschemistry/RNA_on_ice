The "setup.mdp" file includes code that will move the trimer so that the ribose bisecting vector is at an initial angle of 90 degrees. From there, the "counfout.gro" file can be used to find preferred ribose orientations (ie, in other folders).

All the .sh files and code in the folder use the index from /MD/UGG_RNA/ that includes the ribose bisector pull code groups.
